# Commentary

Staged Turkish commentary artifacts copied from `../prose_generation` on
2026-07-30 and refreshed with editorially promoted layer-2 ayah outputs on
2026-08-19.

This directory contains finalized commentary content artifacts only. Source
prompts, prompt manifests, packets, scripts, orchestration records, agent logs,
and experimental output variants remain in `../prose_generation`.

## Origin

The files originated in the `prose_generation` repository under:

- `_commentary/outputs/`;
- `_channel/layer3/outputs/`;
- `_commentary/work/layer_3_channel_commentary/generated/bundles/`;
- selected finalized S87 channel review/prose folders under
  `_commentary/outputs/`.

The source repository checkpoint before the final filename normalization was:

```text
prose_generation commit 8631bc5a846d8495701332c01fc4d3a4adce5e97
```

The imported files were copied from the local `prose_generation` working tree
after the following cleanup steps:

- merged `_commentary/outputs/sNNN-default/` output folders into
  `_commentary/outputs/sNNN/`;
- normalized finalized Turkish ayah filenames by replacing
  `default.v2.5.6-sol-high` with `tr`;
- renamed bare ayah summary files from `*.prose.summary.md` to
  `*.prose.summary.tr.md`;
- removed byte-identical untagged S18 duplicate ayah files after confirming
  matching `.tr.md` copies existed;
- normalized layer-3 surah reading Markdown filenames from
  `*.surah-reading.md` to `*.surah-reading.tr.md`.
- copied active editorial layer-2 ayah outputs from `_commentary/outputs/`
  while ignoring `archive/`, then normalized filenames by removing
  `.editorial` before `.tr.md`.

## Workflows

`ayah/detailed/tr/` contains detailed ayah commentary generated by the
commentary layer-2 ayah workflow. Each ayah may have reader prose, evidence,
friction, index, and findings files. These files preserve the detailed
evidence-bearing surface.

`ayah/summary/tr/` contains compact ayah summary prose generated from available
detailed ayah commentary outputs by the summary generation workflow.

`surah/detailed/tr/` contains channel-informed surah commentary artifacts from
two channel workflows:

- `_channel/layer3/outputs/` produced the main layer-3 surah reading set:
  `*.surah-reading.tr.md`, `*.channel-briefs.json`, and
  `*.discovery-hypotheses.json`;
- `_commentary/work/layer_3_channel_commentary/` produced compiled channel
  bundles via `build_channel_bundle.py`; selected finalized S87 review and
  prose outputs were copied beside those records.

## Exclusions

The import intentionally excludes:

- `_commentary/inputs/` prompts and manifests;
- `_channel/layer3/inputs/`, `_channel/layer3/packets/`, and
  `_channel/layer3/prompts/`;
- `_commentary/work/` scripts, tests, prompts, and workspace documentation;
- orchestration notes and agent-operation records;
- experimental variants such as ablations, no-focus pilots, and model-suffixed
  non-normalized outputs;
- S87 channel draft/adjudication/friction files.

Those files remain upstream as build or review context and are not canonical
consumer-facing commentary artifacts.
