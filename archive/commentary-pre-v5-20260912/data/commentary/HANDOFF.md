# Commentary Handoff

Date: 2026-08-19

Path: `quran-data/data/commentary/`

This directory is a staged import of finalized Turkish commentary artifacts from
`../prose_generation`. It is not yet folded into `quran-data` release metadata,
checksums, or a formal release tag.

## Language

The commentary content is Turkish and is stored under `tr/` locale folders.

Markdown files with `.tr.md` are Turkish prose/commentary files. JSON files use
English structural keys and stable identifiers, while generated reader-facing
text fields are Turkish. Some JSON values use ASCII-only Turkish transliteration
because that is how the source workflow emitted them.

## Ayah Detailed Commentary

Path:

```text
data/commentary/ayah/detailed/tr/sNNN/
```

These are detailed ayah-level commentary artifacts generated by the layer-2
ayah commentary workflow. They preserve the full evidence-bearing surface for
each available ayah, not just reader prose.

File families:

| Pattern | Count | Language | Contains |
| --- | ---: | --- | --- |
| `S_A.prose.tr.md` | 1,865 | Turkish | Reader-facing continuous ayah commentary prose. |
| `S_A.evidence.tr.md` | 1,850 | Turkish with source refs/IDs | Evidence surface for claims in the prose, including references and traceability notes. |
| `S_A.friction.tr.md` | 1,850 | Turkish | Ambiguities, instruction friction, caveats, and unresolved issues recorded by the writer. |
| `S_A.index.tr.md` | 1,072 | Turkish with refs/IDs | Ayah-level index or navigation surface for the detailed output. |
| `S_A.findings.tr.md` | 0 in the current imported set | Turkish if present | Findings index for readings carried by the prose. The current import path allows this type, but no normalized `.findings.tr.md` files are present in `quran-data`. |

The `S_A` prefix means `surah_ayah`, for example `100_1.prose.tr.md`.

Coverage is partial. Available folders are the surahs whose finalized normalized
outputs existed upstream at copy time; absence of a file means the corresponding
ayah/file family was not available in the imported source set.

## Source And Normalization Notes

The files were copied from the local `prose_generation` working tree after
filename normalization. The checkpoint before final normalization was:

```text
prose_generation commit 8631bc5a846d8495701332c01fc4d3a4adce5e97
```

Normalization performed before or during import:

- `_commentary/outputs/sNNN-default/` files were merged into
  `_commentary/outputs/sNNN/`;
- `default.v2.5.6-sol-high` was replaced with `tr` in finalized ayah filenames;
- bare ayah summaries were renamed from `*.prose.summary.md` to
  `*.prose.summary.tr.md`;
- byte-identical untagged S18 duplicate ayah files were removed after their
  `.tr.md` counterparts were confirmed;
- layer-3 surah readings were renamed from `*.surah-reading.md` to
  `*.surah-reading.tr.md`.
- active editorial layer-2 outputs in `_commentary/outputs/` were promoted as
  canonical ayah detailed commentary by copying `*.editorial.tr.md` files and
  removing `.editorial` from the imported filenames; `archive/` was ignored.

## What Is Not Included

The following source material was intentionally excluded:

- prompts, prompt manifests, packets, scripts, tests, and orchestration notes;
- agent logs and local workspace state;
- `_ayah_commentary/` S100 model-comparison and pilot variants;
- ablation/no-focus/model-suffixed experimental variants;
- S87 channel draft/adjudication/friction files;
- `.DS_Store` files.

Those remain upstream in `../prose_generation` as build, review, or experiment
context. This directory is for staged consumer-facing commentary artifacts.
