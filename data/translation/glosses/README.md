# Translation Glosses

Locale-specific root gloss outputs for translation workflows.

Layout:

```text
data/translation/glosses/locales/<locale>/<root-envelope>.json
```

Current locale payloads:

- `locales/tr/`: Turkish dictionary-v2 gloss results copied from `dictionary/v2/gloss_generation/results/tr/`.

Each locale folder should carry its own `SOURCE.md` with source repository, source commit, copy date, coverage count, and selection rules.
