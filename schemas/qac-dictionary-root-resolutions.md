# QAC dictionary root resolutions, version 1

`data/bridges/qac-dictionary-root-resolutions.json` is the source-owned
dictionary identity gateway for QAC root keys. It is generated by
`scripts/bridges/build_dictionary_root_resolutions.py` from exact Arabic
Furuq root identities and the seven evidence-bound decisions in
`data/bridges/qac-dictionary-reviewed-aliases.json`. The QAC-to-Furuq
occurrence map supplies observational targets for audit, not dictionary
identity.

The top-level object has `schemaVersion` =
`qac-dictionary-root-resolutions-v1`, a policy string, SHA-256 hashes for the
input bridge TSV, Furuq SQLite database, and reviewed-alias JSON, `rootCount`,
`counts`, and `roots`. Each root row has:

| Field | Meaning |
| --- | --- |
| `qacRoot` | Spaced Arabic QAC root key. |
| `qacRootJoinKey` | Unspaced Arabic key used for exact lookup. |
| `resolution` | `exact_root`, `reviewed_alias`, or `unresolved_identity`. |
| `rootIds` | Dictionary root IDs approved for this QAC key; empty when unresolved. Composite identities can have more than one ID. |
| `observedTargetIds` | Distinct occurrence-derived Furuq targets retained as evidence. |
| `withheldTargetIds` | Observed targets absent from `rootIds`; never publish these as automatic dictionary identities. |
| `missingEntryRootIds` | Approved root IDs lacking a transferred Turkish entry. |

The reviewed-alias source is an object with `schemaVersion` =
`qac-dictionary-reviewed-aliases-v1`, `reviewedOn`, and `aliases`. Each alias
names `qacRoot`, approved `rootIds`, a full `branchRef`, the SHA-256 of that
branch's exact UTF-8 `source_phrase_ar`, and a short editorial `reason`.
The builder verifies the branch hash before accepting an alias.

## Consumer rule

Use `qacRootJoinKey` to get `rootIds` when a consumer needs dictionary
identity for a QAC root. Preserve the `unresolved_identity` result and empty
`rootIds`; do not substitute an `observedTargetId`. The occurrence-derived
`qac-furuq-v4-root-map.sqlite.gz` and form-level `qac-v4.sqlite.gz` remain
useful for their documented audit and form lookup purposes, but neither is a
dictionary identity authority.

For an exact QAC word or lemma with cited competing derivations, apply
`data/bridges/qac-dictionary-word-root-analyses.json` only after its exact
selector matches. Its ranked alternatives are scoped to that selector and
do not modify this root-wide map. See
`schemas/qac-dictionary-word-root-analyses.md` for the selector and evidence
contract.

This gateway has 1,642 QAC root rows: 1,629 exact identities, seven reviewed
aliases, and six unresolved identities. The source audit and repeatable build
commands are in `data/bridges/ROOT-DICTIONARY-REVIEW.md`. Regression checks
for withheld targets and unresolved keys are in
`tests/test_turkish_dictionary.py`.
